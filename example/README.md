# 示例项目

在 IDE 中选择「打开项目」，填写下表对应的文件夹路径。每个项目包含 C++ 源码和可视化配置，可直接运行；本次新增的六个示例不需要输入。

| 文件夹 | 算法 | 建议观察 | 预期结果 |
| --- | --- | --- | --- |
| binary_search | 二分查找第一个相等元素 | left_bound、right_bound、mid、answers | `4 -1 -1 -1` |
| quick_sort | 快速排序 | a、递归调用栈 | `-2 -2 0 1 4 4 7 9` |
| knapsack | 0/1 背包 | 二维 dp、item、c | 最大价值 `12` |
| floyd_warshall | 全源最短路 | 二维 dist、图节点上的 dist[0] | 源点 0 的距离为 `0 0 3 4 ∞` |
| union_find | 并查集与路径压缩 | parent 对应的森林、components | `4 4 4 4 -1 -1 -1`，集合数 `3` |
| topological_sort | Kahn 拓扑排序 | 入度、队列、访问状态、有向边 | `0 6 1 2 3 5 4` |

源码中 `@probe` 注释所在行是便于观察变化的断点位置。快速排序与并查集包含函数调用，可在该处设置断点后继续，或按 F7 进入函数。

Floyd 示例包含零权边、负权边和孤立点，没有负环；无边使用 `INF`。并查集使用 `-1` 表示根，便于通过通用父节点绑定查看森林。拓扑排序包含孤立点，修改为有环输入时会输出 `CYCLE`。

原有项目仍在各自目录：`bfs`、`dijkstra`、`sort`、`tree`、`large`、`recursion`、`blank`。`recursion` 运行后输入一个非负小整数，例如输入 `5` 输出 `120`。

验证新增示例：在项目根目录执行 `npm run test:algorithms`。测试实际调用 GCC/GDB，检查断点、单步变化标记、最终变量、图绑定与标准输出，并包含拓扑有环变体和二分查找全程单步。
