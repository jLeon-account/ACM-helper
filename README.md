# 使用说明

面向算法竞赛初学者的本地教学 IDE。使用真实 GCC / GDB 执行 C++17 程序，逐行采集状态，让数组、矩阵、结构体字段与图节点的数值在原位置更新并变绿。

## 启动

Windows 双击 `start.cmd`，然后访问 **http://127.0.0.1:4173**。保留启动窗口；关闭窗口即停止服务。

首次安装需要 Node.js 22+、npm，以及支持 Python 的 MinGW GDB 和 GCC。当前开发机已使用 GCC 16.1.0 / GDB 17.2 验证。依赖锁定在 `package-lock.json`。

```powershell
npm ci
npm run build
npm start
```

开发模式：`npm run dev`。默认端口 4173，可通过 `PORT` 环境变量调整。工具链默认使用 PATH 中的 `g++` 和 `gdb`；可在右上角设置里指定绝对路径，也支持 `CXX` / `GDB` 环境变量。

本地服务只监听 127.0.0.1，校验 Host、Origin 和随机会话令牌。这里运行的是用户自己的本地教学代码，尚未提供面向不可信远程代码的沙箱，不应直接发布到公网。

## 教学流程

1. 「新建项目」创建项目，或「打开项目」填写本地文件夹路径。示例在 `example/` 下各自的项目文件夹中，通过同一个打开项目入口使用。
2. 编辑并保存代码。默认使用交互终端：运行后点击控制台，输入数据并按回车。
3. 点击代码行号左侧的空白栏设置断点，或直接「开始调试」。
4. 「下一步」执行一行；「进入函数 / 跳出函数」用于观察递归；「继续」运行到下一断点，不补录中间动画。
5. 变量在原单元格更新为绿色，新变化的边框强调 400 ms；绿色保留到重新运行或重置标记。自动单步等待本步完成后继续，不积压命令。
6. 右下切换普通变量 / 可视化，点击底部调用栈可查看不同递归层。
7. 拖动四个分区的分界线调整大小，布局保存在本机浏览器。

快捷键采用 CLion 的 Windows 常用映射：F8 下一步、F7 进入函数、Shift+F8 跳出函数、F9 继续、Shift+F9 开始调试、Shift+F10 运行、Ctrl+F2 停止、Ctrl+F8 切换光标所在行断点、Ctrl+S 保存。快捷键在编辑器与终端获得焦点时均可使用。浏览器或系统保留的快捷键可能由外层窗口拦截。

自动播放速度可输入 0.1—100 步/秒，实际速度受采集及渲染耗时限制，逐步等待而不积压命令。

交互终端使用 Windows ConPTY，支持输入回显、回车、退格、粘贴、多轮输入和终端尺寸调整。输出遵循程序真实缓冲行为：`cin.tie(nullptr)` 配合 `sync_with_stdio(false)` 后，单写 `\n` 不保证立即刷新；要即时显示可使用 `std::endl` 或 `std::flush`。设置中仍保留「运行前预置输入」模式。终端需要 Windows 10 1809 或更新版本。

青色源码行表示下一条将执行的位置；淡金色表示上次暂停位置对应的执行起点。一次源码步可能包含函数调用或一行内多次赋值，不能把它理解为逐条机器指令。

## 图与树绑定

「结构绑定」描述数据含义，不按算法名称选择动画。项目配置存放在 `projects/<id>/.cppide.json`。

| 来源 | 必填内容 | 举例 |
| --- | --- | --- |
| 邻接矩阵 | 二维数组、节点数、节点下标起点、无边标记 | `G`、`n`、`0`、`INF` |
| 边表数组 | 起点数组、终点数组、边数、节点数；权重可空 | `from`、`to`、`m`、`n`、`weight` |
| 父节点数组 | 父节点数组、节点数、无父节点标记 | `parent`、`n`、`-1` |

边表记录固定从数组下标 0 开始，节点编号可从 0 或 1 开始。零权边只有在无边标记不是 0 时才存在。矩阵的无向边会去重；自环与平行边会阻止树布局。树 / 森林按连通分量布局，根节点可指定。图上位置可以拖动并保存。

可绑定 `visited` 状态数组、`dist` 数值数组、数值标签数组，以及 `u` / `v` 当前节点和边端点。当前节点 / 边可限制在指定代码行范围生效。状态使用青色，当前关注对象使用金色，观察到的数值变化使用绿色。`INF` 显示为 `∞` 需显式配置。

边权默认隐藏；鼠标悬停在某条边上时，只高亮该边并显示其权重，避免交叉处多个标签遮挡。

最多 200 个节点、500 条边。超限或范围无效会报告原因，不构造假的节点或边。当前首版支持数值标签；复杂容器与指针关系需要后续适配。

## 大数组

- 大于 200 个元素默认启用分页窗口与同值折叠。连续至少 16 个相同值的区间可折叠，保留范围、端点和原因。
- `a[100]` 或 `a[90..110]` 可以固定查看；也可以使用下标定位和上一 / 下一窗口。
- 隐藏不意味着停止监测。完整监测的连续基础类型数据总量默认 8 MiB；超限数组不进行全量采集，须在「监测范围」中指定有效区间。
- 初始化判断是启发式：批量同值更新、或同一位置连续对相邻元素写入相同值，可能归类为初始化。允许关闭，也可固定查看纠正。
- 只读未改的数据也可能被折叠；同值写入、两次暂停间改变后恢复无法通过快照差分识别。
- 普通修改后恢复初值，若两次变化分别被观察到，历史绿色仍保留。

## 实现结构

`src/` 为 React + Monaco + Cytoscape + xterm.js 界面；`server/` 为 Node 本地服务、GDB/MI3 调度、GDB Python 采集器与 Windows 原生终端组件；`shared/` 为消息类型与图关系处理；`example/` 是可直接修改的真实 C++ 项目。

编译复制项目到本机临时工作目录，使用 `-std=c++17 -g -O0 -fno-omit-frame-pointer -fno-inline`。程序输入输出与 GDB 控制通道分离。变量数值来自停止状态的 GDB，C++ 整数以字符串传输，避免 JavaScript 丢失 64 位整数精度。

为避免最后一次「继续」停留在旧数据，编译时加入函数退出钩子，在 `main` 返回、栈帧尚未释放时自动采集最终快照，再继续结束进程。包含 `return` 表达式产生的修改；已析构的容器不承诺仍有效。异常终止、强制停止、直接调用 `exit` 不经过这一正常返回检查点，画面保留最近有效暂停状态。该编译过程不改写用户源文件。

普通变量和可视化使用相同快照；完整数组在采集器中按块比较，只向前端发送显示窗口、折叠摘要和变化元素。图绑定独立读取所需的小型有效范围。图节点位置不因数值改变而重新布局。

## 验证

```powershell
npm test
npm run test:integration
npm run test:algorithms
npm run test:terminal
npm run test:api
npm run build
```

集成测试会实际编译并调试 C++，需可用 GCC / GDB。覆盖 Dijkstra 的 `INF → 5`、百万数组隐藏修改与恢复、vector 排序、预置输入，以及后续增加的边界样例。性能数据由每个快照自身计时，显示在状态栏，不包含动画等待。

`test:algorithms` 验证二分查找、快速排序、0/1 背包、Floyd、并查集和拓扑排序，核对单步变化、最终快照和输出，并测试拓扑有环变体及连续单步到退出。打开方法和预期结果见 [示例说明](example/README.md)。

## 当前边界

单个 `.cpp` 入口加项目头文件；单线程。数值数组、二维数组、普通结构体及 libstdc++ 数值 vector 有专用展示，`vector<bool>` 等特殊布局暂不支持。局部变量初始化状态无法始终可靠判断，界面不会把未知状态当作可靠初值。没有完整执行历史、反向执行或每次写入追踪。

后续服务器化需要额外建设进程隔离、CPU/内存/时间限制、并发队列与用户管理；本次不包含服务器部署。
